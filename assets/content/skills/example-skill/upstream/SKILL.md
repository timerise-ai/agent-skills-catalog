# Example skill

## When to use

- A catalog has no synced skill yet and needs one to build its pages.

## When NOT to use

- **Any real task**: sync a real skill instead.

## Hard rules

> **Never ship the placeholder.** Delete this folder once a real skill is synced.

## Quick start

1. Run `npm run skills:sync`.
